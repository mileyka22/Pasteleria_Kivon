## Resumen práctico
- git add . -> prepara archivos

git push -> sube esos cambios a la nube.
### Consejo: si es la primera vez que subes tu proyecto, asegurate de haber hecho antes :
- git remote add origin https://github.com/mileyka22/Pasteleria_Kivon.git
- git branch -M main
- git push -u origin main
